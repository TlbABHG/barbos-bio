Logga in

För att lägga till eller ändra spel sparar den här sidan filen bankroll/bets.json i ditt GitHub-repo barbos-bio, samma fil som den franska sidan använder. Den behöver en GitHub-token, som bara sparas i den här webbläsaren.

  1. Öppna GitHub → ny ”Fine-grained token”.
  2. Repository access: Only select repositories → barbos-bio.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Skapa token, kopiera den och klistra in den här.
Lokalt testläge: inget skickas till GitHub

Nytt spel

Skriv spelet på franska, t.ex. Vitality gagne eller Vitality Vainqueur. Filen delas med den franska sidan, som visar texten som den är, och den svenska sidan översätter automatiskt till Vitality vinner.

Lägg till varje val med sitt odds, och skriv spelet på franska (t.ex. NAVI gagne). När en match är klar anger du resultatet för det valet: kombinationens resultat och totalodds räknas ut automatiskt. Om valen kommer från flera turneringar kan du till exempel skriva ”Multi-tournois” som turnering.
