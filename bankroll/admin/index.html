Connexion

Pour ajouter ou modifier des paris, cette page enregistre le fichier bankroll/bets.json dans ton dépôt GitHub barbos-bio. Il lui faut un token GitHub, qui reste uniquement dans ce navigateur.

  1. Ouvre GitHub → nouveau « Fine-grained token ».
  2. Repository access : Only select repositories → barbos-bio.
  3. Permissions → Repository permissions → Contents : Read and write.
  4. Génère le token, copie-le et colle-le ici.
Mode test local : rien n’est envoyé sur GitHub
